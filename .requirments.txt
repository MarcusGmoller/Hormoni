# =============================================================================
# SUPER SIMPEL GUIDE (for ikke-tekniske brugere)
# =============================================================================
# I arbejder altid på en BRANCH (ikke direkte på main).
# Jeres branch i dette projekt hedder: layout
#
# Brug PowerShell kommandoer herunder, præcis som de står.
# =============================================================================

1) Åbn projektet i terminal
   cd C:\Users\cathr\OneDrive\Desktop\Hormoni-repo

2) Hent nyeste kode fra jeres branch (gør dette først hver gang)
   git checkout layout
   git pull origin layout

3) Installer pakker (kun når nødvendigt)
   npm.cmd install

4) Start projektet lokalt (host)
   npm.cmd run dev
   Åbn derefter:
   http://localhost:3000

5) Stop projektet igen
   Tryk: Ctrl + C
   Når du bliver spurgt "Terminate batch job (Y/N)?", skriv: Y
   Tryk Enter

6) Når du er færdig med dine ændringer (push til GitHub)
   git add .
   git commit -m "Kort besked om hvad du har lavet"
   git push

7) Hvis git push bliver afvist
   (Det betyder at der er kommet nye ændringer fra andre)
   Kør:
   git pull origin layout
   Løs eventuelle konflikter hvis Git beder om det
   Kør derefter:
   git push
